# NKR Ground Control Station 0.2.0

First packaged cross-platform release of NKR GCS.

## Highlights

- Native low-latency RTSP video using GStreamer on Linux and PyAV/FFmpeg on Windows.
- Isolated Flatpak package for Steam Deck and desktop Linux.
- Self-contained Windows x64 build.
- DJI-inspired video-first operator interface.
- Selectable Steam Deck, Xbox Controller, and DualSense input profiles.
- Persistent cross-platform application settings.

## Downloads

- **Steam Deck / Linux:** `nkr-gcs-linux-x86_64.flatpak`
- **Windows 10/11 x64:** `nkr-gcs-windows-x64.zip`
- **Verification:** `SHA256SUMS.txt`

See [INSTALL.md](https://github.com/benderitto/nkr-gcs/blob/v0.2.0/INSTALL.md) for installation and Tailscale setup.
